Background microphone session

This clip demonstrates the microphone foreground service lifecycle. The test microphone is silent in this recording. Android's screen recorder does not capture the communication audio track in these recordings; the screen companionship clip below shows actual AI replies as on-screen captions.

  1. The user opens a character chat and starts a voice session with microphone access already granted.
  2. The user switches to the Android home screen while the session remains active. Android shows microphone use and Yyo's ongoing notification.
  3. The user returns to the same session after the elapsed call time exceeds eight minutes, then hangs up. The recording shows the session exiting and Yyo's notification and microphone indicator disappearing.

Waiting intervals are shortened with explicit transition cards. The app interface and elapsed timer are unchanged. Open or download the background microphone recording (MP4)

Screen companionship

Foreground service types: mediaProjection, microphone, and mediaPlayback for the character's spoken replies during the active session.

Recording limitation: the screen recorder does not capture communication audio. Actual AI replies appear in Yyo's captions, and the shared screen appears in its preview. No replacement speech or soundtrack has been added.

  1. The user opens screen companionship from a character chat and chooses to start a session.
  2. After voice connects, Android asks the user to approve screen sharing. Yyo uses the shared screen to understand and comment on the current activity.
  3. The user can stop sharing in Yyo or through Android's screen-sharing controls. Stopping the companion session also ends its voice conversation.

Waiting intervals are shortened with explicit transition cards; the app interface and Android consent dialog are unchanged. Open or download the screen companionship recording (MP4)
