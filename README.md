# Yyo 安装包

[Yyo](https://yyo.si) 的桌面端和 Android 安装包都发布在这个仓库的 [Releases](https://github.com/LinearGameAI/yyo-releases/releases) 里，网站的下载页直接链接这里的文件。

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片 / Intel） | `Yyo-<版本>-mac-arm64.dmg` / `Yyo-<版本>-mac-x64.dmg` |
| Windows 10 / 11 64 位 | `Yyo-<版本>-win-x64.exe` |
| Linux | `Yyo-<版本>-linux-x86_64.AppImage` / `Yyo-<版本>-linux-amd64.deb` |
| Android 8.0+ | `Yyo-<版本>-android.apk` |

- 标签 `v<版本>-test`：测试版（预发布），连接测试环境，对应 https://test.yyo.si
- 标签 `v<版本>`：正式版

源码在 [LinearGameAI/web-hermes](https://github.com/LinearGameAI/web-hermes)（`desktop/` 桌面端、`app/` 手机 App），这里只放构建好的安装包。
